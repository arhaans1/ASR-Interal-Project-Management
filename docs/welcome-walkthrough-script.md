# Welcome walkthrough: voiceover script

The client portal opens with a short animated walkthrough the first time a client signs in.
These are the lines spoken over each scene. The same lines appear on screen as captions.

## Adding the voiceover

Record (or generate) one audio file per scene and save them as MP3:

```
public/onboarding/voiceover/cam/01.mp3 ... 09.mp3
public/onboarding/voiceover/vsl/01.mp3 ... 09.mp3
public/onboarding/voiceover/webinar/01.mp3 ... 09.mp3
```

Once `01.mp3` exists for a funnel type, the walkthrough plays the clips and each scene
lasts exactly as long as its clip. Until then it runs on a timer with captions only.
The text lives in `src/lib/walkthrough.ts`; change a line there and re-record that scene.
